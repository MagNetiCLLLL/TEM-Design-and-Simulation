# 相干传播性能优化实测（2026-10-11）

本轮按固定输入先测量、再修改波场存储、径向 GPU 数据驻留和检查点读取。
没有修改电子源、透镜/偏转器/孔径强度、采样网格、误差阈值或数值精度。
仍使用顶部统一的 CPU/GPU 设置，没有新增计算按钮或设备选择器。

## 实际速度

Windows，NVIDIA GeForce RTX 5090，CuPy 14.1.1，float64/complex128。
计时任务串行执行；GPU 计时在完成后同步。预热与正式测量分开。

| 测量范围 | 优化前 | 优化后 | 加速 |
|---|---:|---:|---:|
| 固定 Si 波场的实际柱内续传播，3×6720×6720，包含文件校验、加载及设备传输 | 9.421 s | 6.157 s | 1.53× |
| 同一 Si 检查点的验证、128²显示、完整网格束心/束宽统计 | 12.027 s | 8.095 s | 1.49× |
| 径向算子基准，1,048,576 点，6 段漂移/C3/孔径操作 | 1267.009 ms | 40.748 ms | 31.09× |
| 笛卡尔算子基准，1536²，6 次规范传播 | 52.493 ms | 47.824 ms | 1.10× |

这些范围不同，倍数不能相乘，也不能当作完整电镜计算的加速倍数。
Si 柱内续传播采用已有的 GPU 执行波场作为固定输入边界，只推进 0.001 mm，
使用本轮开始时保存的当前默认仪器状态；它没有重新执行针尖到样品的全程。
旧 Si 仪器快照不兼容当前格式，因此没有绕过程序的输入检查或迁移旧物理参数。
前后续传播使用完全相同的当前仪器快照和旧波场边界；这是一项局部性能/回归测试，
不用于证明旧波场由当前默认仪器产生。

Si 计时为首次执行后 3 次的中位数；读取测试为 3 次顺序执行的中位数。
没有清空操作系统文件缓存，因此不代表冷磁盘启动速度。
笛卡尔小基准采用同进程交替顺序的 12 组比较，避免 GPU 时钟和调度波动。
径向基准采用便于验证的缩放算子输入，而非真实电镜源参数；前后输入完全相同。

## 分阶段结果与修改原因

实际 Si 柱内续传播的独立剖析记录如下。时间包含子调用，不能逐行求和：

| 调用 | 优化前 | 优化后 |
|---|---:|---:|
| 加载、验证并构造执行模式 | 5.296 s | 2.688 s |
| 数组文件 SHA-256 | 2.611 s / 30 次 | 1.347 s / 15 次 |
| 波场构造/存储初始化 | 2.575 s | 1.669 s |
| 概率统计 | 1.530 s / 32 次 | 0.969 s / 25 次 |
| 规范传播算子 | 0.476 s | 0.458 s |
| 设备到主机传输 | 0.490 s | 0.467 s |

柱内物理计划准备为 0.343 s，前后基本不变，没有把它计入传播加速。
剖析发现预算预检先加载全部复数组，而执行又读取一次。
现在预检读取尺寸元数据；真正使用模式前仍校验完整文件和实际网格。
损坏的检查点仍报错。

1. **波场存储**：公共构造函数继续复制输入；内部新生成的 GPU 数组转交所有权，
   仅改原点/曲率等元数据时复用数组。仍检查有限数值、坐标和曲率。
   CPU 不可变数组可缓存概率；GPU 数组可被调用者改写，所以每次重新计算概率。
   GPU 概率使用双精度融合归约，避免中间模长与平方数组。
2. **径向传播**：每个模式入口上传，传播、相位、球差、孔径、采样检查和细化留在 GPU，
   最后交接至笛卡尔计算时下载。基准上传/下载量各从 192 MiB 减至 24 MiB。
   非圆对称和其他不适用情形继续走原来的二维路径；没有取消物理作用或采样检查。
3. **检查点读出**：同一次请求内复用经过校验的不可变快照，缓存上限为 128 MiB，
   且受既有读出与 RAM 预算约束。请求结束即释放，下一次请求重新校验文件。
   大于缓存限额的模式保持流式读取，显示和统计合并为一遍。
   Si 读出中数组校验/加载从 51 次减至 36 次，模式构造从 9 次减至 6 次；
   该大网格测试的额外快照缓存实际为 0 字节。

## 一致性与范围

- Si 续传播的全部 3 个复振幅数组逐值相同，强度、权重、能量、网格、原点、
  曲率与倾角均相同。没有拟合相位、移位或重新归一化后再比较。
- Si 显示密度逐位相同，积分概率、束心、束宽和能量统计完全相同。
- 径向算子的带径向积分权重复场 L2 差为 **1.66×10⁻¹⁵**，概率差为 0，半径网格逐位相同。
  极小半径处除以半径会放大 FFT 舍入误差，所以没有声称该复数组逐位相同。
- 笛卡尔算子复场最大差为 0，概率归约差为 **2.22×10⁻¹⁶**。
- 文件完整性、采样不足、物理截断、CPU/GPU 对照、取消、缓存释放和内存预算都保留测试。
  无 GPU 的 CI 仅可将明确登记的硬件测试标为未运行，不能把执行失败当作通过。

最终集成覆盖 458 个不同用例，无跳过。首次运行 457 项通过，1 项旧内存预期失败：
小 RAM 预算下应额外预留 64 MiB 的请求内缓存。修正断言后，相关 2 项预算测试通过；
其他已通过用例未重复运行。新建的 3 个测试文件已登记到现有验收范围。
另外修正了基线中已存在的旧数值测试前提：FFT 友好网格已能落在原来的 8 MiB 限额内，
因此用于验证拒绝路径的测试限额改为 6 MiB；这只改变测试输入，不改变软件计算预算。
旧径向路由测试补齐模式身份，并隔离该测试没有验证的另一条孔径优化路径。
