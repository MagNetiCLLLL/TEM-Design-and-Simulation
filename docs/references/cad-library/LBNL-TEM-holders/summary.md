# NCEM TEM Holders

[Original public source](https://foundry.lbl.gov/instrumentation/tem-holders/). Checked location: ThermoFisher/FEI Microscopes, entries 1-3.

## Supported information

- Actual instruments such as TitanX use conventional FEI single- and double-tilt holders; low-background double-tilt holders accept 3 mm specimens secured with clips/spacers.

## Unsupported extrapolations

- This is a physical inventory at an operating facility, not manufacturer machining drawings; shaft lengths or thicknesses cannot be inferred from photographic proportions.
