# Manipulator for rotating and translating a sample holder

[原始公开来源](https://patents.google.com/patent/US20080173813A1/en)。核对位置：Figs. 1A-2C (PDF p2)。

## 能支持的内容

- FEI共同申请的样品圆载体由两侧夹持件实现平移/转动。

## 不支持的外推

- 此处sample holder指被夹持的圆载体，不是普通侧插长杆的完整工程图。
- 不用于普通杆的尺寸或内部机构建模。
