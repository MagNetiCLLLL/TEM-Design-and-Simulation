# Speciman holder and speciman holder movement device

[原始公开来源](https://patents.google.com/patent/US20100006771A1/en)。核对位置：Fig. 1 (PDF p2); [0010] (PDF p4); [0097] (PDF p10-11)。

## 能支持的内容

- 常规侧插杆经导向套、气锁密封进入镜柱；Fig.1 标出杆、外部手柄和两个密封圈。
- [0010]/[0097]给出6-10 mm杆/前端直径范围；X沿杆，alpha绕X。

## 不支持的外推

- 不是Titan/Spectra制造图，未给杆长、手柄直径或薄tip厚度。
- 范围不表示7 mm圆杆可以进入本机5.4 mm极靴间隙。
