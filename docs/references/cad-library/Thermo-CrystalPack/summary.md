# CrystalPack Module

[Original public source](https://documents.thermofisher.com/TFS-Assets/MSD/Application-Notes/crystal-pack-module-application-brochure.pdf). Checked locations: PDF p2 Figs.1-2; brochure AN0070-EN-10-2017.

## Supported information

- The beta axis is usually noneucentric; after calibration for a specific holder, Compucentricity compensates through other stage axes.

## Unsupported extrapolations

- One cannot assume that both rotation axes of every double-tilt holder pass exactly through the specimen center.
- No mechanical exterior dimensions are provided.
