# How do aberration correctors work?

来源：[CEOS GmbH](https://www.ceos-gmbh.de/de/grundlagen/Workshop-Beitraege/01_How-do-aberration-correctors-work-pdf.pdf)；作者：Martin Linck；日期：2025-08-31。

[原始PDF](original.pdf)，文件SHA及状态见[source.json](source.json)。

位置：PDF pp22,24,26,29。

## 能支持

- CETCOR成像光路与附加对准通道。
- DP12位于TL11与TL12之间；DPH1/2与对应HP同Z作用。

## 不能支持

- 无机械毫米尺度。
- 同Z符号不能唯一证明实际径向绕组或磁芯宿主。

本项用于[成像校正器对照](../../../image_corrector_reference.md)，不是OEM制造图授权。
