# CETCOR - Cs Korrektor fuer TEM

Source: [CEOS GmbH](https://www.ceos-gmbh.de/de/produkte/temkorrektoren/cetcor); Author: CEOS GmbH; Date: Webpage undated.

[Original webpage](original.html); for file SHA and status, see [source.json](source.json).

Location: Technische Daten.

## Supported statements

- The manufacturer explicitly gives HxBxT=250x396x306 mm, meaning height/width/depth.
- Lists compatible TEMs including Titan, Themis and Spectra.

## Not supported

- No mounting-interface reference plane is given, and whether the envelope includes external coupling lenses is unknown.
- It cannot be used to compress the entire OL-to-SAD optical path into 250mm or treated as exact CAD for this instrument.

This entry is used for [the image-corrector comparison](../../../image_corrector_reference.md), not authorization to use OEM manufacturing drawings.
