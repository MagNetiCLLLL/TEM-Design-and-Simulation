# CETCOR - Cs Korrektor fuer TEM

来源：[CEOS GmbH](https://www.ceos-gmbh.de/de/produkte/temkorrektoren/cetcor)；作者：CEOS GmbH；日期：网页未署日期。

[网页原文](original.html)，文件SHA及状态见[source.json](source.json)。

位置：Technische Daten。

## 能支持

- 厂家明示HxBxT=250x396x306 mm，即高/宽/深。
- 列Titan、Themis、Spectra等兼容TEM。

## 不能支持

- 无安装接口参考面，不知外形是否包含外接耦合镜。
- 不能将全OL到SAD光程压缩成250mm或当本机精确CAD。

本项用于[成像校正器对照](../../../image_corrector_reference.md)，不是OEM制造图授权。
